# Задание 005 — выгрузить сырьё по шести пустым коммерческим страницам

Приоритет: после 004, можно раньше 002 и 003, если те окажутся долгими.
**Ничего не менять.** Только чтение и выгрузка.

## Зачем

Облачная сессия пишет тексты для шести страниц, но собственной связи с сайтом
у неё больше нет: исходящая сеть контейнера ограничена белым списком, и
`regiongbi.ru` в него не входит — прокси отвечает 403 на CONNECT. Проверять
страницы снаружи она теперь не может, поэтому фактуру снимаешь ты.

Из базы, а не из рендера: в рендере разметка уже испорчена автоформатированием,
а нам нужен исходный текст, чтобы не потерять то, что там уже написано.

## Какие страницы

```
resheniya
zastroyshchiku
zhkh-i-vodokanalu
dorozhnomu-podryadchiku
dorozhnoe-zhbi
catalog
```

Слаги указаны как в адресах; уточнить ID через `wp post list --post_type=page`.
Если слаг не найден или их несколько — не подгонять, а выгрузить что есть и
отметить в отчёте.

## Что сделать

1. По каждой странице положить в `packages/resheniya-src/<slug>.html` результат:

```
wp post get <ID> --field=content
```

   Именно в файл, не через `echo` — кириллицу и кавычки не терять.

2. Собрать `packages/resheniya-src/meta.csv` со столбцами:
   `slug;ID;roditel_slug;title;rank_math_title;rank_math_description;slov_v_kontente`.
   Мета берутся из `wp post meta get <ID> rank_math_title` и
   `rank_math_description`; пустое значение так и оставить пустым.

3. Собрать `packages/resheniya-src/vhodyashchie-ssylki.csv`: для каждой из шести
   страниц — какие ещё страницы сайта на неё ссылаются. Поиск по содержимому:

```
wp post list --post_type=page --post_status=publish --fields=ID,post_name --format=csv \
  --s='/resheniya/zhkh-i-vodokanalu/'
```

   Столбцы: `cel;ID_istochnika;slug_istochnika`. Это нужно, чтобы починить
   сироту `/resheniya/zhkh-i-vodokanalu/` — но саму починку не делать.

4. В отчёте назвать: сколько слов сейчас в каждой из шести страниц и сколько
   у каждой входящих ссылок.

## Чего не делать

Не писать тексты, не менять содержимое, не трогать меты. Тексты пишет облачная
сессия, заливка будет отдельным заданием с пакетом и `deploy.sh`.

## Проверка результата

В `packages/resheniya-src/` шесть html-файлов (или меньше, если страница не
нашлась — тогда это названо в отчёте), `meta.csv` и `vhodyashchie-ssylki.csv`.
