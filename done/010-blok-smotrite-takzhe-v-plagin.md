# Задание 010 — перенести блок «Смотрите также» из контента в mu-плагин

Приоритет: после 009. Делается **в два этапа**: сначала одна страница, потом
остальные. Второй этап не начинать, пока первый не проверен живьём.

## Почему переносим

Блок сейчас лежит копией в содержимом 19 страниц. Из-за этого:

- 37 карточек без фотографии рисуются пустым серым прямоугольником
  (`background:#eef2f0`) — выглядит как поломка вёрстки;
- любая правка вида блока = правка девятнадцати страниц;
- тема прячет пустышки правилом CSS — заплатка, которую пора убрать.

Диагноз из задания 002 про `wpautop` **не подтвердился**: блок собран одной
строкой и автоформатированием не рвётся. Чинить надо не переносы, а заглушки.

## Этап 1 — плагин и одна страница

### Плагин `mu-rz-related.php`

Сверься со списком (`ls -1 wp-content/mu-plugins/`) — имени `mu-rz-related.php`
там быть не должно.

1. **Связи берутся из того, что уже есть.** Разбери
   `packages/related-src/*.html` и составь таблицу «slug страницы → четыре
   slug'а, на которые она ссылается». Порядок сохранить. Связи подбирались
   осмысленно — не заменять их автоматическим подбором «по родителю» и не
   придумывать новых.

2. **Вывод** — фильтром `the_content`, после основного содержимого, только для
   страниц из таблицы.

3. **Ключевое условие:** если в содержимом страницы уже есть маркер
   `<!-- rz-related -->`, плагин **не выводит ничего**. Это позволяет чистить
   страницы по одной, не получая два блока подряд.

4. **Картинка карточки** — миниатюра целевой страницы через
   `get_the_post_thumbnail_url($id,'medium')`. Не зашивать пути к файлам:
   поменяется картинка в медиатеке — блок должен подхватить сам.

5. **Карточка без миниатюры — не серый прямоугольник.** Вместо него текстовая
   плитка: фон `#F2F1EC` (бумажный тон темы), тонкая рамка `#DCD9D0`, по центру
   крупно марка изделия шрифтом заголовков темы. Марку брать из названия
   раздела — аббревиатуру из заглавных букв (`Днища колодцев ПД по ГОСТ…` → `ПД`,
   `Люки чугунные ЛЧ и дождеприёмники…` → `ЛЧ`). Если аббревиатура не
   выделяется однозначно — **не выдумывать**, показать первые два слова
   названия. Подпись под плиткой остаётся прежней, как сейчас.

6. Заголовок блока — `<h2>Смотрите также</h2>` без инлайнового цвета
   `#23483a`: цвет задаёт тема, старый зелёный остался от прежней палитры.

### Первая страница

Убрать блок из содержимого **только** `/catalog/koltsa-kolodeznye-ks/`
(ID 108) — вырезать всё от `<!-- rz-related -->` до `<!-- /rz-related -->`
включительно. Правка контента идёт пакетом с публикатором, не руками в админке.

### Проверка этапа 1

- на `/catalog/koltsa-kolodeznye-ks/` ровно один блок «Смотрите также»,
  четыре карточки, серых прямоугольников нет;
- на любой другой из 18 страниц блок тоже ровно один — тот, что из контента;
- обе страницы отдают 200, в консоли браузера пусто.

**Остановись здесь и напиши отчёт.** Этап 2 — следующим прогоном.

## Этап 2 — остальные восемнадцать

Только после того, как этап 1 проверен. Вырезать блок из содержимого
оставшихся 18 страниц тем же пакетом, прогнать проверку по всем 19 адресам:
на каждом ровно один блок и ни одной заглушки `#eef2f0`.

После этого в теме (`mu-rz-theme.php`) убрать временное правило, прячущее
пустые плитки, — оно станет ненужным и будет мешать в будущем. Убирать
**только** его, остальную тему не трогать.

## Общие требования

- Бэкап до каждого этапа. Правка контента — через `deploy.sh`; правка
  mu-плагина — по четырём условиям раздела 4 вручную, как в задании 008.
- После заливки `wp cache-enabler clear` и проверка живьём.
- Идемпотентность: повторный прогон пакета не должен ни плодить дубли, ни
  вырезать лишнее.
