# Задание 012 — сменить счётчик Метрики на сайте

Приоритет: **первый**, вперёд остальных. Пока не сделано, сайт шлёт данные в
счётчик, к которому ни у кого нет доступа, и целей не видит никто.

## Что произошло

Счётчик **110459313**, стоявший на сайте, создан на неизвестном яндекс-аккаунте:
ни у владельца, ни у `izdeliya-gbi` его в списке нет, настройки отдают 403.
Управлять им нельзя — ни целей завести, ни отчёт посмотреть.

Заведён новый счётчик в том же аккаунте, где Вебмастер:

```
номер: 112302967
имя:   regiongbi.ru
часовой пояс: Москва, валюта RUB, Вебвизор включён
```

В нём уже созданы четыре цели типа «Целевое событие», условие «Совпадает»:

| цель | идентификатор |
|---|---|
| Заявка с формы | `zayavka` |
| Клик по телефону | `tel` |
| Клик по почте | `mail` |
| Открыт прайс | `price` |

Терять нечего: у старого счётчика история почти пустая — кликов из поиска ноль.

## Что сделать

1. **Найти все места**, где встречается `110459313`:

```
cd ~/regiongbi.ru/public_html
grep -rn '110459313' wp-content/mu-plugins/ .htaccess 2>/dev/null
grep -rn '110459313' wp-content/themes/ 2>/dev/null
wp db query "SELECT option_name FROM wp_options WHERE option_value LIKE '%110459313%'"
```

   Ожидаются `mu-regionzhbi-setup.php` (код счётчика) и `mu-rz-celi.php`
   (вызовы `ym`). Если номер найдётся ещё где-то — не пропускать, но и не
   править вслепую: сначала посмотреть, что это за место, и написать в отчёт.

2. **Заменить на `112302967`** во всех найденных местах кода mu-плагинов.
   Номер должен остаться в одном месте на файл — переменной или константой,
   а не рассыпанным по тексту.

3. **Убрать отправку старой цели `call`** из `mu-regionzhbi-setup.php`: клик по
   телефону сейчас шлёт два события, `tel` и `call`. Цели `call` в новом
   счётчике нет, так что вреда нет уже сейчас, но лишний вызов надо убрать,
   чтобы через полгода никто не гадал, почему звонков две штуки на один клик.
   Ничего другого в этом плагине не трогать.

4. **Проверить живьём**, а не по коду: открыть главную и карточку товара,
   убедиться, что в исходном коде страницы номер `112302967` и старого номера
   нет нигде.

## Порядок

Бэкап до правки. Это правка mu-плагинов, не контента, — значит четыре условия
раздела 4 AGENTS.md выполняются по отдельности, как в задании 008.
После заливки `wp cache-enabler clear`.

## Проверка результата

- `grep -rn '110459313' wp-content/mu-plugins/` не находит ничего;
- главная и карточка отдают 200, в исходном коде виден `112302967`;
- в консоли браузера нет ошибок;
- в отчёте указано, в скольких местах и каких файлах была замена.
