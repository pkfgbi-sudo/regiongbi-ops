# Задание 002 — собрать сырьё для починки блока «Смотрите также»

Приоритет: после 001. **Ничего на сайте не менять** — это разведка, а не правка.

## В чём проблема

Блок «Смотрите также» на страницах каталога вставлен многострочной разметкой.
Автоформатирование WordPress (`wpautop`) разрывает карточку без фотографии на
две плитки: пустой серый прямоугольник (`background:#eef2f0`) и отдельную
подпись со ссылкой на тот же раздел. Проверено последовательным обходом всех
88 адресов карты сайта 03.09.2026:

- блок есть на 21 странице;
- заголовок «Смотрите также» с зелёным `color:#23483a` — на 20 страницах;
- пустых серых заглушек — **37 штук на 18 страницах**.

Пример: `/catalog/koltsa-kolodeznye-ks/` — из пяти плиток настоящих три.

Тема сейчас прячет пустышки правилом CSS, но это заплатка. Чинить надо в
содержимом: собирать блок одной строкой, без переводов строк внутри `<a>`,
и не рисовать серую заглушку там, где фотографии нет.

## Что сделать

Собрать по каждой из 21 страницы точные данные, из которых облачная сессия
сложит пакет замены. Для этого нужно **содержимое из базы**, а не отрендеренная
страница: в рендере разметка уже испорчена автоформатированием.

1. Найти страницы, где в содержимом есть `Смотрите также`:

```
cd ~/regiongbi.ru/public_html
wp post list --post_type=page --post_status=publish --fields=ID,post_name --format=csv \
  --s='Смотрите также'
```

2. Для каждой такой страницы выгрузить кусок содержимого от `<!-- rz-related -->`
   (или от `<div style="margin:40px 0 8px">`, если маркера нет) до закрывающего
   `</div>` блока. Класть по одному файлу на страницу в
   `packages/related-src/<slug>.html`.

3. Заодно собрать в `packages/related-src/index.csv`: ID, slug, сколько
   карточек в блоке, у скольких есть `<img`, у скольких заглушка `#eef2f0`.

## Что важно

- Ничего не менять и не публиковать. Только чтение и выгрузка.
- Если у страницы блок выглядит иначе, чем описано, — не подгонять под шаблон,
  а выгрузить как есть и отметить это в отчёте.
- Кавычки и кириллицу не терять: выгружать через `wp post get <ID> --field=content`
  в файл, а не через echo.

## Проверка результата

В `packages/related-src/` лежит по файлу на каждую найденную страницу плюс
`index.csv`, и число строк в csv совпадает с числом файлов.
