# Задание 003 — сплошная проверка товарной микроразметки

Приоритет: после 002. **Ничего не менять** — это обход и подсчёт.

## Повод

В отчёте по 001 отмечено: на `/catalog/koltsa-kolodeznye-ks/ks-10-9/` три блока
`Product` (КС 10-5, КС 10-6, КС 10-10), ни у одного нет `offers`, цена лежит
только в `additionalProperty`. И на странице с адресом `ks-10-9` нет товара с
именем «КС 10-9». Похоже на осечку генератора `tools/rz-extract-products.php`.
Неизвестно, сколько ещё страниц задето, — это и надо выяснить.

Заодно проверяется исходное допущение: считалось, что Product отдаётся на
10 карточках и ItemList на 3 страницах рядов. Проверка шла по сайту из 88
адресов; теперь их 226.

## Что сделать

1. Взять список адресов **из карты сайта** (`sitemap_index.xml` и вложенные),
   а не из старых списков. Обходить **последовательно**, с браузерными
   заголовками; пустой или короткий ответ — ошибка замера, а не «признака нет».

2. Для каждого адреса по **сырому HTML** (не разбором графа) посчитать:
   сколько вхождений `"@type":"Product"`, сколько из них содержат `"offers"`,
   есть ли `"@type":"ItemList"`.

3. Сложить в `packages/product-audit.csv`: `url;product;product_s_offers;itemlist;
   http_kod;bayt`. Разделитель — точка с запятой, кодировка UTF-8.

4. Отдельно свериться с базой: у каких страниц есть мета `_rz_product` и
   совпадает ли число товаров в мете с числом в HTML.

```
cd ~/regiongbi.ru/public_html
wp post list --post_type=page --post_status=publish --fields=ID,post_name --format=csv \
  --meta_key=_rz_product
```

5. Отдельным списком в отчёте: страницы, где имя товара не совпадает с адресом
   страницы (как `ks-10-9` → КС 10-5/10-6/10-10).

## Чего не делать

Не перегенерировать разметку и не править `rz-extract-products.php`. Сначала
надо понять масштаб; правку соберёт облачная сессия по результатам этого обхода.

## Проверка результата

`packages/product-audit.csv` содержит строку на каждый адрес карты сайта, число
строк совпадает с числом адресов, и в отчёте названы итоги: сколько страниц с
Product, сколько из них без `offers`, сколько с расхождением имени и адреса.
