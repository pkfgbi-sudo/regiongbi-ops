# Задание 016 — блок «Смотрите также», этап 2

Приоритет: после 015. Этап 1 залит и проверен, теперь остальные 18 страниц.

## Что сделать

1. Вырезать блок из содержимого оставшихся 18 страниц (от `<!-- rz-related -->`
   до `<!-- /rz-related -->` включительно) — пакетом с публикатором,
   идемпотентно. Список — те же 19 страниц из `packages/related-src/index.csv`
   минус `koltsa-kolodeznye-ks`, уже сделанная.

2. Заливать через `deploy.sh` **после** того, как в задании 015 починена его
   калитка. Если 015 почему-то не сделано — этап 2 не начинать: старая калитка
   откатит исправный пакет.

3. Проверить по всем 19 адресам: на каждом ровно один блок «Смотрите также»,
   заглушек `#eef2f0` ноль, число карточек прежнее.

4. После этого убрать из `mu-rz-theme.php` временное правило CSS, прячущее
   пустые плитки, — оно больше не нужно. **Только его**, остальную тему не
   трогать. Заливать через `deploy-plugin.sh` из задания 015.

## Проверка результата

- `#eef2f0` не встречается ни на одной из 19 страниц;
- в `mu-rz-theme.php` нет правила, прячущего пустые плитки, и вёрстка блока
  при этом не поехала — проверить живьём две-три страницы, а не по коду.
