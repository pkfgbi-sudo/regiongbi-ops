старого пакета значило бы откатить чужую работу.

«было» обязано встретиться в содержимом ровно один раз, иначе позиция не
собирается и печатается предупреждение.

```

В пакете у каждой позиции ровно три поля: `url`, `slug`, `content`. Ни меты,
ни SEO-полей, ни заголовков — по требованию «больше в этих карточках ничего
не трогать». Публикатор при отсутствии `parent` и `roditel_slug` родителя не
переписывает, при отсутствии `post_title` — заголовок не трогает.

```

с локального репозитория, поэтому пакет доехал до заливки без промежуточной
отправки на GitHub — отправка одна, в конце цикла, как и просили.

страница заведена» стала бы `vp-03` вместо `vp-01`. Возвращено
